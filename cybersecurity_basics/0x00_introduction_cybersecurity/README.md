# Introduction to Cybersecurity

This project focuses on fundamental cybersecurity concepts implemented through practical shell scripting tasks.

## Project Overview

The tasks in this directory explore:

- Secure password generation
- Hashing and integrity verification using SHA-256
- Cryptographic key generation
- Process inspection and privilege awareness
- Secure release automation

The objective of this project was to build a foundational understanding of applied cybersecurity principles in a Linux environment.

## Files Description

- 0-release.sh: Automates release process using secure scripting practices.
- 1-gen_password.sh: Generates secure random passwords.
- 2-sha256_validator.sh: Validates file integrity using SHA-256 hashing.
- 3-gen_key.sh: Generates cryptographic keys.
- 4-root_process.sh: Identifies processes running with elevated privileges.

## Technologies Used

- Bash scripting
- Linux environment
- SHA-256 hashing
- System process management

## Key Concepts Practiced

- Hashing & integrity verification
- Secure scripting practices
- Privilege awareness
- Randomness & entropy
- Basic cryptographic principles
