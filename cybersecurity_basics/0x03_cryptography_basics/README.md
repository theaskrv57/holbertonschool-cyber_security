# Cryptography Basics & Hashing Techniques

This project focuses on understanding fundamental cryptographic hashing algorithms and password security mechanisms in a controlled lab environment.

## Project Overview

The tasks in this directory explore:

- Hash generation using SHA1, SHA256, and MD5
- Password hashing techniques
- Understanding hash integrity verification
- Dictionary-based password attack simulations (lab environment)
- Using tools such as John the Ripper and Hashcat for educational purposes
- Understanding hash cracking methodologies and defense strategies

The objective of this project was to study how password hashing works, how weak passwords can be compromised, and why secure password policies are critical.

⚠️ All cracking exercises were performed in a controlled laboratory environment using self-generated test hashes.

## Files Description

- 0-sha1.sh: Generates SHA1 hash.
- 1-sha256.sh: Generates SHA256 hash.
- 2-md5.sh: Generates MD5 hash.
- 3-password_hash.sh: Demonstrates password hashing process.
- 4-wordlist_john.sh: Simulates dictionary-based cracking with John the Ripper.
- 5-windows_john.sh: Windows hash cracking simulation.
- 6-crack_john.sh: Demonstrates John usage in lab environment.
- 7-crack_hashcat.sh: Hashcat usage demonstration.
- 8-combination_hashcat.sh: Combination attack simulation.
- 9-attack_hashcat.sh: Demonstrates attack modes for educational purposes.

Supporting files:
- hash.txt
