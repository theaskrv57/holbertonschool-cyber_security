# Linux Security Basics

This project focuses on fundamental Linux security concepts implemented through practical shell scripting tasks.

## Project Overview

The tasks in this directory explore:

- User login inspection
- Active network connection monitoring
- Detecting incoming connections
- Basic firewall rule configuration
- Service auditing
- System security checks
- Packet capture and traffic analysis
- Network scanning techniques

The objective of this project was to develop foundational defensive security skills in a Linux environment.

⚠️ All scanning and analysis activities were conducted in a controlled lab environment for educational purposes only.

## Files Description

- 0-login.sh: Checks currently logged-in users.
- 1-active-connections.sh: Displays active network connections.
- 2-incoming_connections.sh: Identifies incoming connections.
- 3-firewall_rules.sh: Displays or configures firewall rules.
- 4-network_services.sh: Lists active network services.
- 5-audit_system.sh: Performs basic system security audit.
- 6-capture_analyze.sh: Captures and analyzes network traffic.
- 7-scan.sh: Performs network scanning in lab environment.
