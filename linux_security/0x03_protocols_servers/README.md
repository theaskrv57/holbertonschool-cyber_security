# Protocols & Server Security

This project focuses on analyzing network protocols, auditing server configurations, and understanding common service vulnerabilities.

## Project Overview

The tasks in this directory explore:

- Firewall configuration and management
- System auditing techniques
- Service hardening strategies
- Identifying running services and exposed ports
- Securing NFS, SNMP, and SMTP services
- Understanding Denial-of-Service (DoS) concepts
- Cipher analysis and encryption awareness
- Network-level security configuration

The objective of this project was to understand how network services operate, how misconfigurations can introduce vulnerabilities, and how to secure server environments effectively.

⚠️ All testing and configuration changes were performed in a controlled lab environment.

## Files Description

- 0-iptables.sh: Configures firewall rules.
- 1-audit.sh: Performs server security audit.
- 2-harden.sh: Applies hardening techniques.
- 3-identify.sh: Identifies exposed services and ports.
- 4-nfs.sh: Analyzes NFS service configuration.
- 5-snmp.sh: Reviews SNMP security settings.
- 6-smtp.sh: Examines SMTP service security.
- 7-dos.sh: Demonstrates DoS concept in lab environment.
- 8-cipher.sh: Reviews cipher configurations.
- 9-firewall.sh: Implements additional firewall protections.
