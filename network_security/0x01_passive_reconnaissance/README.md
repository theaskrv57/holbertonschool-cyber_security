# Passive Reconnaissance & OSINT

This project focuses on passive reconnaissance techniques used in cybersecurity to gather publicly available information about target domains.

## Project Overview

The tasks in this directory explore:

- WHOIS information gathering
- DNS record enumeration (A, MX, TXT)
- Comprehensive DNS querying
- Subdomain discovery techniques
- Report generation and structured documentation
- Open-source intelligence (OSINT) methodologies

The objective of this project was to understand how attackers and defenders gather information about exposed infrastructure without directly interacting with target systems.

⚠️ All reconnaissance activities were conducted against publicly available information in a controlled lab environment for educational purposes only.

## Files Description

- 0-whois.sh: Retrieves WHOIS information for a domain.
- 1-a_record.sh: Extracts A record DNS information.
- 2-mx_record.sh: Retrieves MX records.
- 3-txt_record.sh: Extracts TXT records.
- 4-dig_all.sh: Performs comprehensive DNS queries.
- 5-subfinder.sh: Enumerates subdomains using passive methods.
- holbertonschool.com.csv: Structured DNS data output.
- holbertonschool_report.md: Reconnaissance findings report.
