# Active Reconnaissance & Service Enumeration

This project focuses on active reconnaissance techniques used in cybersecurity to identify exposed services and potential vulnerabilities in a controlled lab environment.

## Project Overview

The tasks in this directory explore:

- Port scanning and service discovery
- Web server identification
- Directory enumeration
- Identifying injectable parameters (lab simulation)
- Database structure discovery (controlled environment)
- Enumeration of hidden resources

The objective of this project was to understand how attackers identify attack surfaces and how defenders can detect and mitigate such exposure.

⚠️ All activities were conducted in an isolated lab environment designed for educational and ethical security testing purposes.

## Files Description

- 0-ports.txt: Results of port scanning and service discovery.
- 1-webserver.txt: Identified web server technologies.
- 2-injectable.txt: Lab-based injectable parameter identification.
- 3-database.txt: Database enumeration findings (lab environment).
- 4-tables.txt: Extracted table structure (controlled testing).
- 5-hidden_dir.txt: Hidden directory enumeration results.
- Flag files: Challenge-based validation artifacts.

## Technologies & Tools Used

- nmap
- dirsearch / gobuster (enumeration tools)
- HTTP inspection
- Basic SQL injection testing (lab environment)
- Service fingerprinting tools

## Key Concepts Practiced

- Active reconnaissance
- Port enumeration
- Service fingerprinting
- Web application attack surface mapping
- Injection awareness
- Ethical hacking methodology
