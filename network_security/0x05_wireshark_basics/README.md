# Wireshark & Packet Analysis Basics

This project focuses on analyzing network traffic at the packet level using Wireshark in a controlled lab environment.

## Project Overview

The tasks in this directory explore traffic generated by various scanning techniques and analyze how protocols behave during reconnaissance activities.

The objective of this project was to understand how network packets are structured and how different scan types appear on the wire.

⚠️ All traffic captures were performed in an isolated lab environment for educational and ethical purposes only.

## Files Description

- 0-ip_scan.txt: Analysis of basic IP scan traffic.
- 1-tcp_syn.txt: Packet-level breakdown of TCP SYN scan.
- 2-tcp_connect_scan.txt: Analysis of TCP connect scan behavior.
- 3-tcp_fin.txt: FIN scan packet analysis.
- 4-tcp_ping_sweep.txt: TCP-based ping sweep analysis.
- 5-udp_port_scan.txt: UDP port scanning packet inspection.
- 6-udp_ping_sweep.txt: UDP ping sweep traffic.
- 7-icmp_ping_sweep.txt: ICMP-based host discovery analysis.
- 8-arp_scanning.txt: ARP scanning packet analysis.
