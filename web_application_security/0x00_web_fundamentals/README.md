# Web Security Fundamentals

This project focuses on understanding common web application vulnerabilities through controlled lab-based exercises.

## Project Overview

The tasks in this directory explore:

- Host Header Injection
- Cross-Site Scripting (XSS)
- Remote Code Execution (RCE) concepts
- Payload crafting in lab environments
- Understanding web server request manipulation
- Identifying insecure configurations

The objective of this project was to study how common web vulnerabilities arise, how they can be detected, and why secure coding practices are critical.

⚠️ All payload development and testing were performed in intentionally vulnerable lab environments for educational purposes only.

## Files Description

- 1-host_header_injection.sh: Demonstrates Host Header manipulation in lab setup.
- 3-xss_payload.txt: Example XSS payload used in controlled environment.
- 5-ticket.txt: Lab validation artifact.
- 7-rce_payload.txt: RCE concept demonstration in vulnerable lab.
- Flag files: Challenge validation outputs.

## Technologies & Concepts

- HTTP request manipulation
- Web application architecture
- Input validation flaws
- Client-side vs server-side vulnerabilities
- Secure development awareness

## Key Learning Outcomes

- Understanding web attack surface
- Recognizing injection vectors
- Identifying misconfigurations
- Ethical vulnerability testing methodology
- Security mindset development
