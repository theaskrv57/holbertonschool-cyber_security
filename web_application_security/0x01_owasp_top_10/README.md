# OWASP Top 10 – Web Security Analysis

This project focuses on studying and understanding the OWASP Top 10 most critical web application security risks through controlled lab exercises.

## Project Overview

The tasks in this directory explore common web vulnerabilities aligned with the OWASP Top 10 framework, including:

- Injection flaws
- Broken authentication
- Sensitive data exposure
- Security misconfiguration
- Access control weaknesses
- Vulnerability exploitation in lab environments

The objective of this project was to understand how these vulnerabilities arise, how they can be detected, and how secure development practices mitigate them.

⚠️ All activities were conducted in intentionally vulnerable lab environments for educational purposes only.

## Files Description

- 1-xor_decoder.sh: Demonstrates encoding/decoding logic in controlled lab scenario.
- 4-vuln.txt: Vulnerability analysis notes.
- Flag files: Challenge validation artifacts.
- salam.py: Supporting script used for lab experimentation.

## Technologies & Concepts
