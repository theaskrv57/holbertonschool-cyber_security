# Burp Suite Fundamentals

This project focuses on understanding web application security testing using Burp Suite in controlled lab environments.

## Project Overview

The tasks in this directory explore core Burp Suite functionalities including:

- Proxy interception
- HTTP request manipulation
- Repeater usage
- Intruder basics
- Identifying injection points
- Analyzing server responses
- Session handling awareness

The objective of this project was to develop practical skills in manual web application testing and understand how vulnerabilities can be identified through traffic inspection and request tampering.

⚠️ All testing was performed in intentionally vulnerable lab environments for educational and ethical purposes only.

## Tools Used

- Burp Suite
- HTTP protocol analysis
- Web vulnerability testing labs

## Key Learning Outcomes

- Manual request manipulation
- Identifying injection vectors
- Understanding authentication flows
- Parameter tampering
- Recognizing insecure configurations
- Developing an offensive security mindset
