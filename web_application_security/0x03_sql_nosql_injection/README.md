# SQL & NoSQL Injection – Vulnerability Analysis

This project focuses on studying SQL and NoSQL injection vulnerabilities in controlled lab environments.

## Project Overview

The tasks in this directory explore:

- Identifying SQL injection vulnerabilities
- Understanding query manipulation techniques
- NoSQL injection concepts
- Parameter tampering in web applications
- Analyzing server-side query behavior
- Recognizing insecure input handling patterns

The objective of this project was to understand how injection vulnerabilities arise, how they can be detected through manual testing, and how secure coding practices mitigate these risks.

⚠️ All testing was performed in intentionally vulnerable lab environments for educational purposes only.

## Files Description

- vuln.txt: Vulnerability analysis notes.
- req.txt: Sample HTTP request analysis (lab environment).
- Flag files: Lab validation artifacts.

## Technologies & Concepts

- SQL databases
- NoSQL databases
- HTTP request manipulation
- Input validation flaws
- Query structure awareness
- Secure coding principles

## Key Learning Outcomes

- Understanding injection attack vectors
- Manual detection of vulnerable parameters
- Differentiating SQL vs NoSQL injection logic
- Awareness of mitigation strategies
- Ethical security testing methodology
